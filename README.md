## 🛠️ Stack Tecnológico
* **Core:** React 18 + TypeScript + Vite.
* **Estilizado:** Tailwind CSS + Vanilla CSS + Glassmorphism.
* **Animaciones:** Framer Motion + Canvas 2D de alta tasa de refresco.
* **Síntesis Acústica:** Web Audio API (Zero-Bandwidth, síntesis aditiva y granular nativa).
* **Despliegue:** GitHub Pages a través de GitHub Actions.

## 🚀 Ejecución Local y Compilación

```bash
# Entrar al Hub Maestro
cd experiencia-18

# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
Acceso en navegador: `http://localhost:3018/` o `http://localhost:4173/`
